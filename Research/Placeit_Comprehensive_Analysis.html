Placeit · Envato 旗下 · 4 万+ Mockups · 2026 Q2

Guadalajara → Envato：
Placeit 的"Mockup 生成器"传奇

Placeit 是 POD 行业里"Mockup 生成 + 设计模板"领域的领导者，2012 年在墨西哥 Guadalajara 创立，被 Envato（澳洲设计资源市场 + Envato Elements 母公司）以未披露价格收购。 Placeit 提供 40,000+ Mockups + 智能模板 + 设计工具，主要客群是设计师 + POD 卖家 + 营销团队。"5 分钟生成专业 T 恤 mockup"是其杀手锏。截至收购前 ARR 已超过 $3M，55,000+ 付费客户（含 Google / Facebook / Oracle）。

02

发展概况

起源

2012 Guadalajara 设计师创业

2012 年在墨西哥 Guadalajara（墨西哥科技中心）创立。早期专注"快速生成专业产品 mockup"—— 设计师不再需要 Photoshop 手工合成 T 恤效果图。

关键转身

从 mockup 到全栈设计资源

从单一 mockup 工具扩展到智能模板 + maker 工具 + logo 生成器 + 视频模板。覆盖整个设计资源生态。

被 Envato 收购

Envato 最大收购

未披露金额，但被认定为 Envato 历史最大收购。Envato 是澳洲的设计资源 marketplace（含 Envato Elements / ThemeForest 等）。Placeit 加入后增强 Envato 的"AI + 模板"竞争力。

客户增长

55,000+ 含 Google / Facebook / Oracle

87% 客户来自墨西哥之外 = 全球化定位。客户包括财富 500 公司 = 进入企业级市场。
