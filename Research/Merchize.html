一、执行摘要

Merchize 是一家成立于 2019 年的越南 POD(Print-on-Demand,按需印刷)与全球履约服务平台,总部位于河内,是母公司 Foobla(Foobla Technology Co., Ltd.) 旗下的核心业务。Foobla 早年(约 2014 年)以 WordPress 主题/插件品牌 ThimPress 起家,后转型为电商基础设施和跨境工具公司,推出 Merchize。

截至 2026 年初,Merchize 已发展成:

  • 全球约 1,000 名员工(官网),其中Latka数据显示2025年9月核心运营团队约 54人,差异主要源于工厂工人/合同工口径不同
  • 越南河内拥有 ~70,000 平方英尺(约 6,500 ㎡)自有工厂,日产能上限 10万单
  • 6 大区域生产/履约中心:越南、美国、欧盟、英国、中国、澳大利亚
  • 30,000+ 商家用户、近 1,000 SKU、覆盖 180+ 国家
  • 2025 年被 Forbes Advisor 评为全球 Top 10 POD 服务商
  • 财务方面:据 Latka,2025 年 9 月 ARR 约 590 万美元,公司一直 自筹资金(bootstrapped),未公开融资记录

五、业务模式

5.1 商业逻辑

Merchize 是典型的 "垂直一体化 POD 平台":既是平台(撮合卖家与渠道),又是工厂(自有产能),又是品牌服务商(packaging、tags),又是物流编排器(美/欧/英/澳/中区域中心)。卖家无需库存、无 MOQ、无月费(基础版),按履约收费,卖家保留差价利润。

5.2 收入构成(推断)

收入板块说明客户类型
POD 履约费(主)每单按基础成本+生产费+物流费计入,卖家定价决定利润空间独立卖家、Etsy/Shopify 卖家
Storefront 订阅$79/月、$299/月,亦有 $0/月的纯履约 Lite 版需要独立网站的卖家
FBA 服务制造 + Amazon FBA 仓配 + 标签合规处理Amazon 头部卖家
TikTok Shop 履约满足 TikTok SLA 的快速履约,DTG / AOP / 刺绣 / 家居装饰TikTok Shop 美国卖家
Walmart Marketplace 履约近 1,000 SKU 覆盖 Walmart 入驻所需品类Walmart 卖家
Branding 服务缝唛标、吊牌、定制包装、拉链袋等D2C 品牌客户
SWAG 服务企业/团队定制礼品和员工周边B 端企业
Bulk Production批量定制(超过分级阈值享批发价)需要批发的客户

5.4 印刷工艺

支持 DTG(直喷)、Sublimation(热升华)、AOP(全幅满印)、UV、DTF(转移膜)、刺绣、激光切割等主流印刷技术,主打 Hawaiian Shirt(夏威夷衫,被认为是平台招牌品类)、AOP 服装和家居 Decor。

支持 Shopify、Etsy、WooCommerce、Amazon、eBay、TikTok Shop US、Walmart、Google Shopping 一键集成,提供 Merchize API 和 Order Desk 中间件接入。

七、中国相关线索深度挖掘

调研结论(基于公开信息):Merchize 在中国 没有自营工厂或独立法人公司,中国履约能力主要通过第三方供应链合作伙伴实现,而非自有产能。中国布局的目的是为美国市场提供补充产能、利用中国制造的多样化 SKU 供应链(如季节性/家居/配饰类)、以及降低单一国别风险。

7.3 中国履约中心定位

  • 主要承担:家居装饰、季节性产品、特殊工艺(如金属、陶瓷、UV 印刷类)、部分 AOP 服装等中国制造优势品类
  • 客户结构:美国市场为主(中国→美国占比最大,VN 工厂披露 China→US 运输平均 7.3 工作日)
  • 对接路径:中国合作工厂生产 → 深圳/广州集货 → 头程发往美国 FBA / 海外仓 / 直发消费者

7.4 中国法人 / 商标 / 团队的可见性

维度公开可查情况
中国独资法人未发现。Merchize 在中国未注册独立公司主体,业务通过越南 Foobla 主体 + 第三方供应链合作完成。
中国办公室/团队未公开办公室或本地员工招聘信息;不排除有少量驻华 BD/采购人员通过供应商体系运作。
中国商标未发现 Merchize 在 CNIPA(国家知识产权局)注册的商标记录公开报道。这是一个潜在风险点 — 中国实行"first-to-file"原则,跨境品牌若进入中国市场而未提前注册,易遭抢注。
供应链合作方主要可识别的关联方为深圳 LuckyLucky 国际供应链,负责物流头程与海外仓配。
面料/原材辅料POD 行业中国华南纺织品供应链(广州番禺、佛山中大、东莞)对越南 POD 工厂均为标配,虽然 Merchize 未明确披露,但行业常识下其越南工厂的部分面料/印染辅料应来自中国华南。

7.5 推断的中国供应链画像

结合 POD 行业惯例与公开线索,推测 Merchize 中国端布局如下:

  1. 仓储+头程:深圳 LuckyLucky 国际供应链(罗湖)担任 FBA 头程货代,处理 China→US/EU 运输
  2. 制造代工:合作华南 OEM 工厂(广州/东莞/义乌方向)做家居、装饰、配饰等品类
  3. 采购/选品:由越南总部 R&D 远程对接,通过义乌/1688 体系做新品开发
  4. 面料/辅料:越南工厂的面料、印花膜、热升华纸、五金等大量来自中国华南
  5. 物流通道:使用主流跨境物流(燕文/云途/递四方等中国线 + Yun Express + 邮政小包等)发美国直发线

风险提示:Merchize 在中国的存在感低、商标未注册、无独资公司,如果未来想进入中国市场或保护品牌权益,需要尽快补足这些基础动作。

十、从零到一:获客与营销策略

10.1 第一阶段(2019-2020):本土越南 MMO 社区起家

Merchize 选择了一条非常聪明的路径:不做付费广告获客,而是嵌入越南本土的"跨境 MMO"(Make Money Online)社区。

  • Facebook Group 中心化获客:建立 Merchize Việt Nam 越南语 Group(11,300+ 成员、每日数百活跃)和 Merchize International Fulfillment Community 国际 Group。POD 创业者本身就在 Facebook 上聚集 — 这是几乎零成本的精准获客阵地。
  • Telegram 越南语 + 国际频道:提供更即时的卖家支持沟通。
  • "为越南卖家做一个本土 POD":越南本土卖家此前只能用 Teespring/TeeChip 等海外平台,语言、客服、付款都有摩擦;Merchize 用越南语客服 + 本土工厂时差优势 + 越南本地银行收款支持,直接抢占了这部分用户。

十一、发展趋势分析

11.1 增长动力

  • POD 行业全球增长 22.5% CAGR(Forbes Jan 2026 引用) — 行业大盘还在快速膨胀
  • TikTok Shop / Walmart Marketplace 等新渠道兴起 — Merchize 的产品矩阵和 SLA 履约能力正好适配
  • Creator Economy(创作者经济)规模扩大,品牌化 D2C 创作者需要"有 Branding 服务的 POD"
  • 越南制造在中美贸易战背景下的结构性红利 — 关税、人工成本、英语沟通能力、地理位置都优于中国
  • AI 工具压缩设计/上架门槛 — Merchize 把 AI 集成到工作流,降低长尾卖家的使用阻力

11.2 主要风险

  • 🚨 Printful、Printify 等头部已实现规模优势和产品丰富度,Merchize 在欧美营销和品牌信任度上仍有差距
  • 🚨 过度依赖美国市场(尤其是 TikTok Shop),而 TikTok 在美国的政治不确定性是潜在系统性风险
  • 🚨 中国合作工厂依赖性、供应链单点风险(中国海关、关税政策、地缘政治)
  • 🚨 商标未在中国注册,品牌进入中国市场存在抢注风险
  • 🚨 Bootstrap 模式扩张速度受限,在与已融资头部竞争时市场份额扩张较慢
  • 🚨 客户口碑评价两极(Trustpilot 上有正面也有客服响应慢的负面),客户支持需要进一步优化

11.3 未来 3 年关键预测

  1. 美国本土制造产能持续扩张 — 应对 TikTok Shop 美国本土时效要求和"Made in USA"营销价值
  2. AI Design Suite 全面取代基础 Mockup 工具 — Merchize 已开始主打 AI 设计/AI 文案
  3. 从纯 POD 升级为"全栈 D2C 基础设施" — 包括品牌设计、广告投放(已通过 Snapchat 合作开始)、CRM 工具
  4. 可能尝试 Series A 融资(若想加速对抗 Printful/Printify)
  5. 东南亚跨境制造红利继续扩大,Merchize 有机会建立"越南 Plus"(印尼/孟加拉/印度)分布式工厂网络

十二、总结与思考

📌 一句话总结

Merchize 是一家由越南 WordPress 极客创立、自筹资金、用社区驱动方式做 POD + 全球履约的 D2C 基础设施公司,代表了越南制造 + 跨境电商 + 程序员创业的新一代故事。

核心成功要素(Why It Works)

  1. 团队基因:Foobla 团队 5+ 年的"远程交付海外用户"经验是关键。WordPress 主题客户和 POD 卖家都是"全球分散的小 B 客户",运营逻辑高度一致。
  2. 差异化定位:同时做"平台(Storefront)+ 工厂(自有产能)+ 物流编排(全球履约中心)+ 品牌服务(Branding)",而不是 Printify 那样的纯撮合平台,在产品质量稳定性上有结构性优势。
  3. 越南制造红利:低成本、关税友好(美越贸易协定)、英语沟通能力、地理上对中美都不远。
  4. 社区运营能力:Facebook Group + Telegram + 越南本土 MMO 圈层耕耘,几乎零成本的精准获客。
  5. 持续产品迭代:每月推 6-7 个新 SKU,响应卖家反馈,跟节日/趋势紧密结合。

对类似创业者/调研者的启示

  • 跨境电商基础设施领域,"垂直一体化 + 自筹资金 + 社区驱动"的剧本是可行的,不一定要烧 VC 的钱
  • 选择一个"母语优势 + 制造业优势"明显的国家做基础设施,后续做全球化扩张时门槛远低于直接做美国本土
  • 从"工具/插件"业务积累的"全球小 B 客户运营能力",可以无缝迁移到 POD/履约/SaaS 等更大赛道
  • 中国制造 + 越南制造的混合供应链,正在成为新一代跨境电商基础设施的"标准答案"

对中国市场的思考

Merchize 的 中国布局是"功能性"而非"战略性":中国是供应链节点(物流、辅料、补充产能),不是市场或品牌阵地。这是越南跨境电商基础设施公司的典型策略 — "用中国制造、卖给美国/欧盟"。如果未来 Merchize 要进入中国 To-B 市场(如服务中国卖家做跨境)或 To-C 市场,需要补足:中国独资法人、CNIPA 商标注册、本地客服团队、人民币收付能力 — 这些目前都付之阙如。
